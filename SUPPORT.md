<h1 align="center">Support</h1>

This page explains where to report problems, suggest improvements, request version support, and get general help with Common Trades.

## Bug Reports

If you have found a reproducible problem with Common Trades, use the **Bug Report** issue form.

Before submitting a bug report:

- make sure you are using a Common Trades version intended for your Minecraft version;
- make sure your mod loader and dependencies are compatible;
- check whether the issue has already been reported;
- try to reproduce the problem consistently.

[Report a bug](https://github.com/IntelligenceModding/CommonTrades/issues/new?template=bug_report.yml)

## Feature Requests

Suggestions for new content and improvements are welcome.

[Request a feature](https://github.com/IntelligenceModding/CommonTrades/issues/new?template=feature_request.yml)

## Version Support Requests

If you would like support for another Minecraft version or mod loader, use the **Version Support Request** issue form.

[Request version support](https://github.com/IntelligenceModding/CommonTrades/issues/new?template=version_support.yml)

## Installation and General Help

GitHub Issues should primarily be used for reproducible bugs, feature requests, and version support requests.

For general questions, use the Intelligence Modding Discord:

https://discord.intelligence-modding.de/

## Security Issues

Potential security vulnerabilities should not be reported through a normal public bug report.

If you believe you have found a security-sensitive issue, report it privately to:

**report AT intelligence-modding DOT de**
